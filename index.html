Generator de parole în Python

Această aplicație prezintă un program Python care generează parole aleatorii, în funcție de opțiunile alese de utilizator.

Ce face programul:

  • Permite alegerea lungimii parolei
  • Utilizatorul decide ce caractere să fie incluse:
    • litere mari
    • litere mici
    • cifre
    • simboluri speciale
  • Generează automat o parolă sigură

Programul este util pentru crearea de parole sigure pentru conturi online sau aplicații informatice.
